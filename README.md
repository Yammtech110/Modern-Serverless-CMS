\# Modern Serverless CMS



A modern full-stack Content Management System built with \*\*Astro\*\*, \*\*TypeScript\*\*, and \*\*Cloudflare\*\*. It provides a fast, scalable, and secure platform for creating and managing websites with a plugin-based architecture, structured content, authentication, and a powerful admin dashboard.



\---



\## ✨ Features



\- Modern Admin Dashboard

\- Rich Text Editor

\- Structured Content Management

\- Plugin Architecture

\- Secure Authentication

\- Role-Based Access Control

\- Media Library

\- REST API

\- Full-Text Search

\- Drafts \& Scheduled Publishing

\- Responsive Design

\- Cloudflare Workers Support

\- SQLite / D1 Database Support

\- Type-Safe Development

\- AI-Friendly Architecture

\## 🚀 Installation



Clone the repository



```bash

git clone https://github.com/YOUR\_USERNAME/modern-serverless-cms.git

```



Go to the project



```bash

cd modern-serverless-cms

```



Install dependencies



```bash

pnpm install

```



Build the project



```bash

pnpm build

```



Run the development server



```bash

pnpm dev

```
